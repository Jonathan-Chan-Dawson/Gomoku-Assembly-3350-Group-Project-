Please prepare the following materials for your project presentation and submission.

A. Presentation slides

Your slides should cover:

- Project design overview: Introduce your game, why it is interesting or new, and explain the ideas and design philosophy behind its graphics and game mechanics. Include pictures and a diagram or flowchart illustrating the game’s internal logic.
- Workload distribution and collaboration: Explain how your team made design decisions, divided responsibilities, and collaborated.
- Module design, implementation, and testing: Describe the design and functionality of each major module, from the initial prototype through implementation and testing. Explain how you improved the game through successive iterations.
- Gameplay session: Demonstrate the game and highlight its main features.
  Future work and Q&A: Discuss possible improvements and be prepared to answer technical questions.

B. Video demonstration

Submit an MP4 video demonstrating the game’s instructions, settings, and gameplay. You may also provide a YouTube video link so that other students can view your game (bonus).

C. Documentation and source code

Submit your source code, project documentation, and a README explaining how to set up, build, and run the game.

D. GitHub repository

Include a link to your game’s GitHub repository. The repository should contain your source code, documentation, README, and GIFs showcasing gameplay.
